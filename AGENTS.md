# Agent instructions

## Research

- Post research as comments on the GitHub issue it belongs to, not as files in the repo. Don't add research notes, findings or recommendations anywhere in the tree.

## Requests to the user

- When you need the user to do something (a decision, a download, access, a manual step), open it as a GitHub issue in this repo, or as a sub-issue of the issue you're working on, and assign it to raunaqgupta. Don't leave it only in the chat.

## Sessions and pull requests

- Work on each issue in its own new session. Don't handle more than one issue in the same session.
- When the work for an issue is done, commit, push, and open the pull request yourself without waiting to be asked.
- After the pull request is merged, archive the session.
